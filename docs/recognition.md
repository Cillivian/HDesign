# 图纸识别

## 流水线

1. **栅格化**：`pdfjs-dist` 渲染 PDF 页面（长边约 2400px，支持页面选择）或解码 PNG/JPG/WebP。
2. **归一化**：灰度、Otsu 二值化、反色自动检测、去噪、≤3° 倾斜校正。
3. **墙体**：先用「长笔画宽度直方图」估计图中墙体填充厚度（poché），只保留达到该厚度的
   水平/垂直实心带；再对双线墙/带填充的双线做配对恢复（长细线成对、间距 8–10px、沿线覆盖率
   投票、与实心墙网络端点接触才保留）。共线合并 + 端点正交吸附后得到墙体图。
   **尺寸标注线、轴网/点划线、轴号圆圈、引出线、家具虚线、门窗弧线都只有 1–2px 宽，不会进入
   墙体掩膜**，因此不会再被当成墙。
4. **房间**：墙体掩膜自由空间连通域 → Moore 轮廓 → Douglas–Peucker + 轴向吸附；
   丢弃过小区域并处理嵌套轮廓。墙体缺失导致渗漏时，合并阶段会改用视觉模型的房间划分（见 6）。
5. **文字与比例**：可选 tesseract 数字/中文识别。OCR 文本只作提示，比例尺以尺寸链为准：
   视觉模型为每条尺寸标注输出 `valueMm` + 尺寸线端点 `span`，客户端用
   `mmPerPx = valueMm ÷ |span|` 计算（按跨度加权中位数 + MAD 剔除异常，绝不使用图片宽度）；
   本地 OCR 比例与标注跨度相差 >10% 时自动纠正，用户两点校准永远不会被覆盖。
   OCR 不可用时按 10mm/px 估算并标注，仍可两点校准。
6. **Vision 增强**（可选）：整图 + 最多 4 张重叠局部图发送给 `deepseek-flash`。
   提示词按 CAD 出图规则区分「墙 / 标注线」、读取四侧尺寸链的每一段、输出尺寸线端点并
   反算比例；本地 CV 为主，AI 补充门窗/房间标签/缺失墙体。
   合并阶段会丢弃「明显薄于本地墙带或落在建筑轮廓之外」的 AI 墙体（疑似标注线），
   并在本地房间分割出现渗漏时改用视觉模型房间。
7. **校对与应用**：叠图显示墙/房间/门窗/尺寸，支持逐段修改厚度/删除、两点校准、
   替换或追加到现有方案；应用后写入结构层并保存锁定底图资产。

## 精度与夹具

`node fixtures/generate.mjs` 生成 3 张已知尺寸的合成图（89㎡ 两室、45㎡ 开间、118㎡ 三居，
含 1.4° 扫描旋转）。`packages/plan-recognition/test/` 验证墙体数、房间数、洞口数、
校准后墙长误差（0.00%）与倾斜校正。样例位于 `apps/web/public/samples/`。

`fixtures/reference/cad-plan-2400.png` 是一张真实 CAD 出图（含尺寸链、轴网、轴号、填充图例、
剪力墙实心块），`test/walls-annotation.test.ts` 用它做回归：墙体必须是 19px 以上的实心/双线墙，
不得有 1–2px 的「标注线墙」，不得在建筑轮廓外的标注带里出现墙，房间数 ≥6。

## 提示词回归探针

修改视觉提示词后，用真实图纸检查识别质量（需要先 `pnpm --filter @hdesign/server dev`）：

```bash
node scripts/probe-parse-plan.mjs fixtures/reference/cad-plan-2400.png --out /tmp/parse-probe
```

输出包括：墙体数量/厚度分布、被误判的细线墙、落在建筑轮廓外的墙、尺寸标注条数与带
`span` 的条数、比例尺与尺寸链真值的误差（参考图真值 ≈ 8.05 mm/px 栅格 / 12.08 mm/px 总图），
并写出 `result.json` 与 `overlay.svg` 方便叠图核对。

## 限制

- 面向正交户型图；曲线/斜墙、手绘草图建议使用底图描图 + 两点校准。
- 复杂图例、极低分辨率扫描仍可能误检，需要人工删除；房间渗漏时会回退到 AI 房间。
- 合成夹具使用点阵字体，OCR 数字识别较差，流程会正确降级到 10mm/px + 人工校准。
- 图纸结果必须人工确认，不构成施工依据。
