# 图纸识别

## 流水线

1. **栅格化**：`pdfjs-dist` 渲染 PDF 页面（长边约 2400px，支持页面选择）或解码 PNG/JPG/WebP。
2. **归一化**：灰度、Otsu 二值化、反色自动检测、去噪、≤3° 倾斜校正。
3. **墙体**：Sobel 方向图 + Hough 投票 → 水平/垂直墙带 → 笔画厚度/双线配对 → 共线合并与分段；
   门窗断口桥接后形成墙体图。
4. **房间**：墙体掩膜自由空间连通域 → Moore 轮廓 → Douglas–Peucker + 轴向吸附；
   丢弃过小区域并处理嵌套轮廓。
5. **文字与比例**：可选 tesseract 数字/中文识别，解析 `3600`、`3.6m`、`3600×2800` 与尺寸链；
   按墙段对齐估计分轴 `mmPerPx`。OCR 不可用时使用两点人工校准，仍不可用则按 10mm/px 估算并标注。
6. **Vision 增强**（可选）：整图 + 最多 4 张重叠局部图发送给 `deepseek-flash`；
   本地 CV 为主，AI 补充门窗/房间标签/缺失墙体；合并去重后带来源与置信度。
7. **校对与应用**：叠图显示墙/房间/门窗/尺寸，支持逐段修改厚度/删除、两点校准、
   替换或追加到现有方案；应用后写入结构层并保存锁定底图资产。

## 精度与夹具

`node fixtures/generate.mjs` 生成 3 张已知尺寸的合成图（89㎡ 两室、45㎡ 开间、118㎡ 三居，
含 1.4° 扫描旋转）。`packages/plan-recognition/test/` 验证墙体数、房间数、洞口数、
校准后墙长误差（0.00%）与倾斜校正。样例位于 `apps/web/public/samples/`。

## 限制

- 面向正交户型图；曲线/斜墙、手绘草图建议使用底图描图 + 两点校准。
- 空心双线墙采用启发式配对；复杂图例可能被误检，需要人工删除。
- 合成夹具使用点阵字体，OCR 数字识别较差，流程会正确降级到 10mm/px + 人工校准。
- 图纸结果必须人工确认，不构成施工依据。
